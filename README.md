# 函数极限可视化 · ε-δ 探索器

高数第一章「智慧实践」作业（题目二：函数极限的 ε-δ 定义）。
单文件网页，零依赖、可离线运行，直接在浏览器里玩转极限的定义。

**在线访问：** https://lxoai.github.io/limit-explorer/

## 三种模式

| 模式 | 对应题目 | 能做什么 |
| --- | --- | --- |
| 函数极限（ε-δ） | 题目二 | 拖动 ε / δ 滑块，实时显示 `[L−ε, L+ε]` 横带与 `(x₀−δ, x₀+δ)` 竖带；曲线在 δ 带内落进 ε 带即高亮为绿，跑出则标红并画红点；可一键「自动匹配 δ」求 δ_max；支持分段函数、左右极限、无穷极限、去心邻域（空心点） |
| 数列极限（ε-N） | 题目一 | ε / N 滑块 + 散点图，n ≤ N 显示为灰区，自动求解最小 N |
| 连续与间断 | 题目三 | 判定连续 / 可去 / 跳跃 / 无穷 / 振荡 / 第二类间断，三行表列出左右极限与函数值，无穷间断画渐近线，还有「填洞」滑块演示可去间断的修补 |

## 一些细节

- **表达式输入聪明**：`2xπ`、`(x+1)(x-1)` 这类省略乘号的写法能自动识别；`pi`、`log10`、`√`、`≤ ≥ ≠ ∧ ∨` 都支持。
- **分段函数**：写成 `x<0:-1; x>=0:1`，条件可以用 `0<x<1` 连写，支持 `&&` / `||`（或 `and` / `or`）。
- **极限值是数值估算**：程序用的是有限采样 + Aitken 外推，结论措辞统一为「采样未发现违例」，不宣称数学证明 —— 这是本作业刻意做的严谨性处理。
- **可导出 PNG**，方便贴进报告。

## 使用

直接浏览器打开 `index.html` 即可（也可以下载下来离线用）。
想从某个预设直接进：`index.html#3`（函数） / `index.html#c0`（连续） / `index.html#c0p100`（连续模式、填洞进度 100%）。
